# CMD-BANK

### Initialise venv on local machine
1. `git clone <repo>`
2. `cd PATH/CMD-BANK`
3. `python3 -m venv venv`
4. `source PATH/venv/bin/activate`
5. `pip install -r requirements.txt`

### Run
`./main`

### Fixes if modules not recognised (venv not activated properly)
1. `source PATH/venv/bin/activate`
